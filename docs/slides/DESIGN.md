# DESIGN.md — kalo 项目介绍

风格路由：技术 / 开源项目分享 → **不命中**学术、咨询、政务三条分支 → 走**通用设计原则** + 自定义科技风。

---

## 1. 画布与母版

- 画布：**1280 × 720**
- 页面 padding：上下 20、左右 72
- 母版三区（内容页严格一致）：

| 区 | 垂直范围 | 高度 | 规则 |
| :- | :- | :- | :- |
| **A · 标题块** | 20 – 120 | 100 | 主标题 36px bold，左对齐；标题下 4px 强调色短横线 |
| **B · 内容区** | 130 – 650 | 520 | 一切正文、表格、图形；禁止越界 |
| **C · 页脚条** | 660 – 700 | 40 | 左：`kalo · github.com/TanTaiwoo07/kalo` 13px 灰字；右：页码 `NN / 14` 13px |

封面（01）、章节扉页（03/07/11）、结束页（14）允许自定义版式，可省略 C 区。

## 2. 颜色系统

深色终端质感 —— 与项目本身（终端编辑器）同源。

| 角色 | hex | 用途 |
| :- | :- | :- |
| **主色（背景）** | `#0F172A` | 页面底色、封面全幅 |
| **辅色（卡片）** | `#1E293B` | 卡片背景、表格隔行、分层架构图的层块 |
| **强调色** | `#38BDF8` | 巨型数字、焦点标注、当前阶段高亮 |
| **中性色** | `#E2E8F0`（文本）/ `#94A3B8`（次级文本）/ `#334155`（边框分隔） | 正文、页脚、描边 |

**渐变方案**：仅封面与结束页使用 `linear-gradient(160deg, #0F172A 0%, #1E293B 100%)`，内容页一律纯色。
**半透明策略**：卡片浮起用 `rgba(56,189,248,0.08)` 浅色覆盖；不用大面积半透明蒙版。

### 色彩面积分配

| 页面 | 主色 | 辅色 | 强调色 | 说明 |
| :- | :- | :- | :- | :- |

| 03/07/11 扉页 | 60% | 20% | **20%** | 巨型编号用强调色 |
| 05 原理页（hero） | 55% | 30% | **15%** | 巨型数字 3.06x |

色彩比例差异明显（hero 页 15–20% vs supporting 页 ≤5%）✓

## 4. 配图与图形系统

- **不使用位图生图**。技术项目的叙事主体是结构关系，SVG 承担全部 L1/L2：架构图、时间轴、终端线框、对比表均为结构化元素（规则允许）。
- L1 主视觉（占 B 区 ≥ 30%）：06 页架构图、12 页引擎结构图、13 页三阶段时间轴、05 页基准表。
- L2 支撑图（≥ 280×180）：04 页终端线框、01/14 页终端装饰。
- L3 角标：不使用（全篇无统一徽标需求，避免位置漂移）。
- SVG 风格统一：线宽 1.5px、圆角 8px、填充用辅色 `#1E293B`、高亮路径用强调色 `#38BDF8`。

## 5. 密度与自检

- 内容页留白 ≤ 25%（扉页 45% 例外，符合过渡页豁免）。
- 容器填充率 ≥ 85%；卡片尾部元素用 `marginTop: 'auto'` 钉底。
- 每页 ≥1 个视觉锚点：巨型数字（≥76px）、SVG 图（≥B 区 30%）或大色块。
- 相邻页视觉重量比 > 1.5:1，禁止流水线感。
- 中文正文单行 ≤ 34 字，最长行宽 900px。
